HealthFirst Pharmacy Inventory Management System (PIMS)

A role-based Java desktop application engineered with Java Swing, MySQL, JDBC, and the Data Access Object (DAO) design pattern. Streamlines pharmaceutical inventory tracking, supplier management, expiration monitoring, and Point-of-Sale (POS) checkout workflows across Administrator and Cashier roles.

View GitHub Repository

System Goals & Architecture

  • Role-Based Security: Separate authenticated dashboards and permissions for Pharmacy Administrators and Cashiers.
  • Administrator Controls: Full CRUD operations for medicines, reorder thresholds, expiry dates, supplier records, user accounts, and management reports.
  • Cashier POS & Stock Check: Real-time medicine search, stock availability checks, shopping cart checkout, and billing history inspection.
  • Clean DAO Separation: Decouple Swing UI components from MySQL persistence via dedicated JDBC DAO classes.

Technical Outcomes

  • Implemented atomic checkout transactions that record sales headers, line items, cashier IDs, and automatically decrement medicine stock quantities in MySQL.
  • Built real-time inventory verification preventing overselling and flagging low-stock / near-expiry medicines via reorder thresholds.
  • Delivered normalized relational MySQL schema scripts with pre-seeded users, suppliers, and pharmaceutical stock.

// DatabaseConnection.java
public class DatabaseConnection {
    private static final String URL = "jdbc:mysql://localhost:3306/healthfirst_pims";
    private static final String USER = "root";
    private static final String PASSWORD = System.getenv("DB_PASSWORD");

    public static Connection getConnection() throws SQLException {
        return DriverManager.getConnection(URL, USER, PASSWORD);
    }
}
