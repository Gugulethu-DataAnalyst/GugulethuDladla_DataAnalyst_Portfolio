LendingClub Credit Risk Analytics Engine

An end-to-end credit risk analytics and predictive modeling pipeline built on the Kaggle LendingClub loan dataset (2.26 million+ records across 161 attributes). The project covers large-scale data cleaning, exploratory analysis, feature engineering, Weight of Evidence (WoE) binning, and default probability modeling to support data-driven lending decisions.

View GitHub Repository

Project Goals

  • Clean and streamline 2.26M+ historical loan records and 161 raw features into an analytics-ready schema.
  • Define clear binary target classes separating resolved good loans (Fully Paid) from bad loans (Charged-Off / Default).
  • Engineer borrower stability, debt-to-income, and revolving credit utilization indicators to isolate default drivers.
  • Train and evaluate interpretable credit risk classification models to guide loan underwriting thresholds.

Key Outcomes & Progress

  • Processed and standardized 1,348,099 resolved loan records, establishing a baseline portfolio default rate of 19.98%.
  • Resolved missingness and type inconsistencies across key financial predictors (dti, revol_util, delinq_2yrs, pub_rec, emp_length).
  • Implemented reproducible JupyterLab workflows and Git version control for modular feature engineering and model scoring.

Code Showcase: Target Engineering & Portfolio Default Segmentation

Python data-wrangling pipeline filtering resolved loan outcomes and computing baseline default risk segmentation.

credit_risk_preprocessing.py 
import pandas as pd
import numpy as np

# Filter for resolved loan outcomes to define binary default target
resolved_statuses = ['Fully Paid', 'Charged Off', 'Default']
df_resolved = df[df['loan_status'].isin(resolved_statuses)].copy()

# Binary target: 1 = Default / Charged-Off, 0 = Fully Paid
df_resolved['default_flag'] = np.where(
    df_resolved['loan_status'].isin(['Charged Off', 'Default']), 1, 0
)

# Impute missing numeric credit bureau attributes using median robustness
for col in ['dti', 'revol_util', 'delinq_2yrs', 'pub_rec']:
    df_resolved[col] = df_resolved[col].fillna(df_resolved[col].median())

default_rate = df_resolved['default_flag'].mean() * 100
print(f"Resolved Records: {len(df_resolved):,} | Portfolio Default Rate: {default_rate:.2f}%")
