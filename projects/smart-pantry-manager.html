Smart Pantry Manager

An offline-first native Android application built in Java (API Level 24+) using Model-View-Adapter (MVA) architecture and SQLite persistence. Tracks household grocery inventory in real time and applies a deterministic boolean subset-matching algorithm ($R \subseteq P$) to recommend meals cookable immediately with zero missing ingredients.

View GitHub Repository

Application Goals

  • Eliminate household food waste and mealtime guesswork with offline-first SQLite pantry tracking.
  • Provide full CRUD inventory management with strict input validation and ISO expiration date tracking (YYYY-MM-DD).
  • Pre-seed a relational SQLite recipe database upon first launch via SQLiteOpenHelper.
  • Enforce a zero-tolerance boolean gatekeeper (RecipeMatcher) that surfaces recipes only when 100% of required ingredients are in stock.

Key Outcomes & Architecture

  • Built custom RecyclerView adapters that refresh pantry items and eligible recipes automatically during Android onResume() lifecycle events.
  • Implemented deterministic set-inclusion matching (R ⊆ P) across 15 pre-seeded structured recipes with step-by-step preparation instructions.
  • Validated empty-string and floating-point quantity constraints prior to SQLite write transactions to guarantee data integrity.

Code Showcase: Strict Boolean RecipeMatcher Engine (R ⊆ P)

Deterministic Java matching logic verifying that every required recipe ingredient exists in the user's active SQLite pantry set.

RecipeMatcher.java 
public class RecipeMatcher {
    /**
     * Evaluates active pantry stock (P) against recipe requirements (R).
     * Returns only recipes where R is a strict subset of P (100% match).
     */
    public static List<Recipe> getCookableRecipes(
            List<Recipe> allRecipes, Set<String> availablePantryItems) {
        
        List<Recipe> matchedRecipes = new ArrayList<>();
        Set<String> normalizedPantry = new HashSet<>();
        for (String item : availablePantryItems) {
            normalizedPantry.add(item.trim().toLowerCase());
        }

        for (Recipe recipe : allRecipes) {
            boolean canCook = true;
            for (String required : recipe.getRequiredIngredients()) {
                if (!normalizedPantry.contains(required.trim().toLowerCase())) {
                    canCook = false; // Zero-tolerance rule: missing even 1 item excludes recipe
                    break;
                }
            }
            if (canCook) {
                matchedRecipes.add(recipe);
            }
        }
        return matchedRecipes;
    }
}
